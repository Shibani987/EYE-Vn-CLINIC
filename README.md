# EYE Vn CLINIC

Static informational website for EYE Vn CLINIC, an eye testing and contact lens clinic in Big Bazar, Berhampur, Odisha.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production site is generated in `dist/` and can be deployed to Vercel as a Vite project. Vercel security headers are configured in `vercel.json`.
